## About the team

Mud Head Car is a student-run robotics team competing in **FIRST Tech Challenge**. Students design, build, program and drive the robot, with support from team coaches. The team also leads match strategy, logistics, art and outreach.

## Inside the code

The robot software archive includes Java code for shooter control and testing. Start with the [`Benjamin-Dev` TeamCode directory](https://github.com/chenwen051116/FTC26910-2026/tree/Benjamin-Dev/FtcRobotController/TeamCode).

| Area | What to explore |
| :--- | :--- |
| **Shooter control** | Turret aiming, hood position and flywheel speed based on distance to the goal |
| **Shot profiles** | Short- and long-range profiles with interpolated hood positions and target RPM |
| **Testing & tuning** | A test TeleOp with adjustable shooter settings, telemetry and FTC Dashboard feedback |
